# plugins

My Claude Code plugin marketplace. It has one plugin, [hstack](plugins/hstack/README.md): a second-opinion
review loop, a "dream" that turns past sessions into project memory, and 24 engineering principles, 22 of which
Claude applies on its own.

To install it in Claude Code:

```text
/plugin marketplace add HanranSong/plugins
/plugin install hstack@hanran
```
